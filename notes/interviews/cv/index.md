# CV - Guía para un CV optimizado para ATS

Guía completa para crear un currículum que supere los sistemas ATS (Applicant Tracking System) y destaque ante los reclutadores.

## 1. El diseño no es lo más importante

Las plantillas muy elaboradas (como muchas de Canva) pueden verse atractivas, pero no necesariamente son las mejores para los sistemas ATS (Applicant Tracking System).

Lo más importante es el contenido del CV:

- Qué lograste.
- Cómo ayudaste a tus empleadores anteriores.
- Qué habilidades puedes aportar.
- Qué resultados generaste.

Un diseño limpio, sencillo y fácil de leer suele funcionar mejor.

## 2. No incluyas fotografía

Evita agregar una foto al CV, ya que muchas empresas prefieren evaluar únicamente la experiencia y las habilidades para reducir posibles sesgos durante el proceso de selección.

## 3. No envíes el mismo CV a todas las vacantes

Uno de los errores más comunes es utilizar exactamente el mismo CV para todas las postulaciones.

Cada vacante busca habilidades diferentes, por lo que es recomendable adaptar el CV para cada oportunidad.

## 4. Identifica las palabras clave

Las palabras clave son términos que describen las habilidades, herramientas, tecnologías y conocimientos que la empresa busca.

Normalmente aparecen en la descripción del empleo.

Puedes utilizar ChatGPT para identificarlas.

### Prompt

> Voy a postularme a esta vacante. ¿Me puedes ayudar a identificar las palabras clave más importantes de esta oferta para incluirlas en mi currículum?
>
> [Pega aquí la descripción del empleo.]

Después, asegúrate de incluir de forma natural esas palabras en las secciones de:

- Resumen profesional.
- Experiencia.
- Habilidades.
- Herramientas.

## 5. Escribe un buen resumen profesional

Debe tener entre **80 y 100 palabras**.

Recomendaciones:

- Escríbelo en primera persona.
- Usa un tono positivo y seguro.
- Explica por qué haces lo que haces.
- Menciona en qué áreas destacas.
- Resume tu experiencia y el valor que aportas.

## 6. Incluye habilidades blandas

Destaca únicamente las habilidades blandas que realmente poseas y que sean relevantes para la vacante.

Lo ideal es incluir entre **5 y 7 habilidades**.

Ejemplos:

- Comunicación.
- Trabajo en equipo.
- Resolución de problemas.
- Adaptabilidad.
- Pensamiento analítico.
- Liderazgo.
- Organización.

## 7. Incluye las habilidades técnicas

También puedes pedirle a ChatGPT que identifique las habilidades técnicas más importantes de la oferta.

### Prompt

> Analiza esta vacante e identifica las habilidades técnicas más importantes que debería incluir en mi CV.

Incluye únicamente las que realmente domines.

Ejemplos:

- React
- TypeScript
- JavaScript
- Node.js
- Next.js
- REST APIs
- SQL
- Git

## 8. Agrega una sección de herramientas

Además de las habilidades técnicas, es útil tener una sección específica para herramientas.

Por ejemplo:

- Figma
- Git
- GitHub
- Jira
- Postman
- Node.js
- VS Code
- Docker

## 9. Cómo redactar la experiencia laboral

Evita escribir únicamente una lista de responsabilidades.

Cada punto debe seguir esta estructura:

**Verbo de acción + cómo lo hiciste + resultado obtenido**

En otras palabras:

> Acción → Método → Resultado

### Ejemplo

❌ Desarrollé la interfaz del sitio web.

✅ Mejoré la interfaz del sitio web mediante cambios centrados en la experiencia del usuario, aumentando el tiempo de interacción de los visitantes en un 30%.

Los verbos de acción ayudan a demostrar impacto y muestran mejor tus capacidades.

Algunos ejemplos:

- Desarrollé
- Implementé
- Optimicé
- Diseñé
- Lideré
- Automaticé
- Integré
- Reduje
- Incrementé
- Mejoré

## 10. Incluye solo la experiencia relevante

Para cada empleo agrega entre **3 y 5 logros**, priorizando aquellos que sean relevantes para la vacante.

Formato recomendado:

**Cargo**
**Empresa**
Si fue remoto, indícalo.

**Ubicación**
**Fecha de inicio – Fecha de finalización**

Ejemplo:

**Frontend Developer**
Alan Co. (Remoto)
Australia
Abril 2022 – Presente

- Incrementé el rendimiento de la aplicación optimizando componentes React y reduciendo los tiempos de carga.
- Implementé nuevas funcionalidades que mejoraron la experiencia del usuario y disminuyeron incidencias reportadas.
- Integré APIs REST para automatizar procesos y reducir tareas manuales.

## 11. Apóyate en ChatGPT

ChatGPT puede ayudarte a:

- Identificar palabras clave.
- Detectar habilidades técnicas.
- Mejorar la redacción del resumen profesional.
- Convertir responsabilidades en logros.
- Adaptar el CV para una vacante específica.
- Optimizar el CV para ATS.
- Corregir gramática y ortografía.
- Mejorar el impacto de cada experiencia laboral.

## Checklist antes de enviar tu CV

- [ ] Diseño simple y limpio.
- [ ] Sin fotografía.
- [ ] Adaptado a la vacante.
- [ ] Incluye palabras clave de la oferta.
- [ ] Resumen profesional de 80-100 palabras.
- [ ] Entre 5 y 7 habilidades blandas relevantes.
- [ ] Habilidades técnicas alineadas con la vacante.
- [ ] Sección de herramientas.
- [ ] Experiencia redactada con logros y resultados.
- [ ] Entre 3 y 5 puntos relevantes por empleo.
- [ ] Ortografía y formato revisados.
